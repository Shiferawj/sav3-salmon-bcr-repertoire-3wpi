# sav3-salmon-bcr-repertoire-3wpi
Analysis scripts for Atlantic salmon B-cell receptor repertoire analysis. Fish were challenged with SAV3 and samples were collected at 3 wks. Balanced samples from each tissue and conditions were analyzed (n=3). HK and spleen were analysed
## Data
Raw RNA-sequencing data are available from the NCBI Sequence Read Archive
under BioProject PRJNA1058957:
https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1058957
The R scripts used MiXCR output imported to R using Immunarch.
## R version and packages
- R version 4.6.1 (2026-06-24 ucrt)
- R packages can be found from the scrip file
